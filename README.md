# Dye Recipe Generator — Updates

This public repository is used only to distribute signed-off application update releases for Dye Recipe Generator.

- Release assets and updater metadata are published here by the private source repository's release workflow.
- Application source code and development files remain in the private `Recipe-Generator` repository.
- Do not upload source code, credentials, tokens, databases, or user data here.

The application checks this repository for updates after receiving the one-time transition release from the existing private update feed.
